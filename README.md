# 바로 GO — 부천 출장마사지·홈타이 안내 사이트

경기도 부천시(원미구·소사구·오정구) 방문 관리(출장마사지·홈타이) 안내용 정적 사이트입니다.
`content/` 패키지의 페이지 정의를 `build.py`가 읽어 정적 HTML을 생성합니다.

## 빌드

```bash
python3 build.py
```

- 본문 2,000자 미만 페이지는 자동으로 `noindex,follow` 처리되고 sitemap에서 제외됩니다.
- 모든 페이지에 **WebPage / BreadcrumbList / Organization / ImageObject** 스키마(JSON-LD)가 자동 주입되며,
  FAQ(`.faq-item`)가 있는 페이지에는 **FAQPage** 스키마가 자동 생성됩니다.
  (방문형 사이트이므로 LocalBusiness 계열 스키마는 사용하지 않습니다.)
- `meta description`이 80자를 넘으면 빌드 리포트에 경고로 표시됩니다.
- 루트(`/`)는 부천 메인(`/`)으로 리다이렉트됩니다.

## 사이트 구조 (총 57페이지)

- 메인: `/`
- 구별 안내(3): 원미구 · 소사구 · 오정구
- 지역별 안내(19): 심곡동, 원미동, 역곡 생활권, 춘의동, 도당동, 약대동, 중동, 상동,
  심곡본동, 소사본동, 범박동, 옥길동, 괴안동, 송내동, 성곡동, 원종동, 고강동, 오정동, 신흥동
- 역세권 안내(허브+13): 부천역, 중동역, 송내역, 역곡역, 소사역, 소새울역, 까치울역,
  부천종합운동장역, 춘의역, 신중동역, 부천시청역, 상동역, 원종역
- 생활권 안내(허브+12)
- 안내 페이지: 예약 안내 · 이용 전 확인사항 · 홈타이 이용 가이드 · 고객센터 · 사이트 소개 · 개인정보처리방침 · 이용약관

### URL/콘텐츠 규칙
- 메뉴명·URL 에는 "출장마사지"를 반복하지 않습니다. 키워드는 SEO Title / H1 / 첫 문단에서만 자연스럽게 사용합니다.
- 번호 행정동(중1~4동, 상1~3동 등)은 대표 동으로 통합합니다.
- 환승역도 역명 기준 1개 URL만 사용하고, 출구별·역+테마 조합 페이지는 만들지 않습니다.

## 배포 전 교체해야 할 항목

- `content/site.py` → `BASE_URL` 을 실제 도메인으로 변경.
- `content/site.py` → `TELEGRAM_PARTNER`(제휴문의)에 별도 텔레그램 계정이 있으면 교체.
  (현재 제작문의·제휴문의 모두 `https://t.me/googleseolab` 로 연결되어 있습니다.)
- `assets/og-image.png`, `assets/apple-touch-icon.png`, `assets/icon-*.png`, `assets/favicon-*.png`
  → "바로 GO" 브랜드 이미지로 교체 권장(현재 SVG 파비콘만 GO 마크로 교체됨).

## 디자인
- CSS 디자인 토큰을 프리미엄 팔레트(옵시디언 네이비 + 샴페인 골드 + 오렌지 액센트)로 교체.
- 푸터 "웹사이트 제작문의 / 제휴문의" 오렌지 버튼은 텔레그램으로 연결되는 컴포넌트 오버레이입니다.
- 폰트는 Pretendard 우선, Noto Sans/Serif KR 폴백.
